# Simple Calculator - Python 🧮

A clean, beginner-friendly Python calculator built with error handling and loop logic.

Built with ❤️ in Bloemfontein on Proline Laptop

## What It Does
A command-line calculator that does 4 operations with smart error handling:
- ➕ Add
- ➖ Subtract
- ✖️ Multiply
- ➗ Divide (with zero-division protection)
- Loop: asks "Do you want to perform another operation?"

## Tech Stack
Python | Functions | Try/Except | While Loops | Input Validation

## How to Run (Locally)
This is a Python script (.py file).

1. Download `calculator.py`
2. Open terminal / command prompt
3. Run:

python calculator.py
